# Shape

The Material Design 3 shape system uses a size-based scale with ten styles:

| Corner                | Value               |
| :-------------------- | ------------------- |
| none                  | 0px                 |
| extra-small           | 4px                 |
| small                 | 8px                 |
| medium                | 12px                |
| large                 | 16px                |
| large-increased       | 20px                |
| extra-large           | 28px                |
| extra-large-increased | 32px                |
| extra-extra-large     | 48px                |
| full                  | calc(infinity* 1px) |

`rounded-full` is implemented with `calc(infinity * 1px)` instead of a large value such as `9999px`, so it does not break element transitions. Note that `shape/tw.css` (the TailwindCSS v4 theme file) maps everything except `full`.

Each style provides a different orientation:

- t
- r
- b
- l
- tl
- tr
- bl
- br

For a detailed description of M3 Shape, see [Definition of M3 Shape](https://m3.material.io/styles/shape/corner-radius-scale).

## Import

### For CSS

```css
@import "@sandlada/material-design-css/shape/utilities.css";
@import "@sandlada/material-design-css/shape/variables.css";
```

### For TailwindCSS v4

```css
@import "tailwindcss";
@import "@sandlada/material-design-css/shape/tw.css";
```

### Directional suffixes

You can combine shape styles with directional suffixes to target specific corners.

<ArticleComponentShow>
<div class="flex gap-1">
    <div class="box rounded-t-extra-large bg-primary"></div>
    <div class="box rounded-r-extra-large bg-primary"></div>
    <div class="box rounded-b-extra-large bg-primary"></div>
    <div class="box rounded-l-extra-large bg-primary"></div>
</div>
</ArticleComponentShow>
